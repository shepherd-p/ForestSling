Compile main.tex using XeLaTeX or Tectonic with elsarticle and fontspec.
Install Arial and Times New Roman; figure fonts are embedded in the PDF inputs.
Required packages are declared in main.tex; all nine figure PDFs are included.
Run xelatex main.tex twice, or use tectonic main.tex.
References are contained in references.tex; no BibTeX run is required.
The companion PDF is the reviewed double-column manuscript.
